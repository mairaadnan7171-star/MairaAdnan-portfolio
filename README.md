# Maira Adnan Portfolio Website

## Overview

This project is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my background, technical skills, academic projects, and contact information. The website is designed with a clean, responsive, and user-friendly interface.

## Features

* Responsive navigation bar
* Home section
* About Me section
* Skills section
* Projects section
* Contact section
* Responsive design for desktop, tablet, and mobile devices
* Smooth scrolling using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Projects Included

* AI Food Recommendation System
* Food Delivery App Database
* Student Management System
* Task Management System
* Rock Paper Scissors Game
* Hangman Game
* Car Recommendation System
* Library Escape Game

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
